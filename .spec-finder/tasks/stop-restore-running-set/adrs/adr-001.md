# ADR-001: Explicit evening/morning trio

## Status

Accepted

## Date

2026-09-01

## Context

A farm operator can Start all closed jars in the current tab from the sidebar, but cannot put a tab or the whole farm down in one action, and cannot bring back only the jars that were running last. Per-panel Close already drops a live view and keeps the login. Start all is the wrong morning verb because it also starts unused closed jars. Auto-sleep, wipe, and bots are product prohibitions. Keyboard start-all/stop were deferred in the account-loop shortcuts packet.

This decision locks the V1 product approach after clarification and an explicit approach choice.

## Decision Drivers

- Verified problem: evening is N Close-panel clicks; morning Start all over-starts unused jars
- Primary user: farm operator (several isolated jars of one game, sometimes a second tab)
- G-01 / G-02 journal: one evening stop of the chosen scope; one morning restore of last non-empty farm
- Non-goals: auto-sleep, schedules, named presets, replacing Start all, keyboard Start all
- Isolation unchanged; stop is close, not wipe

## Decision

V1 is an **explicit trio** next to existing Start all:

1. **Stop this tab** closes running accounts in the active tab only.
2. **Stop whole farm** closes every running account across tabs.
3. **Restore last set** starts the accounts that were running the last time at least one panel was live, and does not start other closed jars.

Start all stays “every closed jar in this tab.” Last-set is one farm-wide memory, not per-tab presets. It updates while anything is running and freezes when the live count hits zero. Keyboard exists for the three new verbs, including while a game panel is focused. Start all stays mouse-only. Nothing auto-starts on launch. Stop never wipes a jar.

## Alternatives Considered

### One Stop menu (approach B)

- **User value:** Less chrome; farm-stop still reachable.
- **Costs/risks:** Whole-farm evening job is buried; G-01 may miss for the second tab.
- **Why not selected:** User chose the explicit trio so both stop scopes stay visible.

### Morning on empty stage (approach C)

- **User value:** Morning restore is the obvious empty-stage click.
- **Costs/risks:** Today’s empty stage starts the first account; one-account path gets worse.
- **Why not selected:** User kept the casual Start path and put restore in the trio.

### Replace Start all with restore

- **User value:** One morning button.
- **Costs/risks:** No one-click way to start unused closed jars in the tab.
- **Why not selected:** Non-goals locked Start all unchanged.

### Mouse-only (no new keys)

- **User value:** Fewer reserved chords.
- **Costs/risks:** Evening/morning still a pointer trip after the first Start, when focus is in a game.
- **Why not selected:** User included keyboard for the new verbs; Start all keys stay out.

## Consequences

### Positive

- Evening can drop a tab or the whole farm without N Close clicks or a wipe.
- Morning can bring back last night’s farm without Start all over-start.
- Start all and per-panel Close remain for other jobs.

### Negative and trade-offs

- Four bulk actions sit together (Start all, stop tab, stop farm, restore); Start all vs restore can be confused.
- A jar closed by hand during the day is not in tomorrow’s restore.
- Three more modifier chords are reserved from the game.
- Restore may start jars on a tab the operator is not looking at (same as running-on-other-tab today).

### Risks and mitigations

- Operator hits Start all in the morning — G-05 keeps Start all; G-02 journal; reconsider replacing or demoting Start all only if that journal fails.
- Accidental farm-stop closes the other game — per-panel Close and stop-this-tab remain; dogfood G-01.
- Chord collision with a game — modifier chords only; remap already exists for documented binds.

## Reversibility

- Hide farm-stop or restore if dogfood never uses one of them.
- Add Start all keyboard only if morning Start all is still a mouse bottleneck after restore ships.
- Revisit last-set-per-tab if a two-game farm needs two morning restores.

## Follow-ups

- Dogfood G-01–G-05 in ~1 week of sessions after ship.
- Exact chords and chrome labels belong in the TechSpec, not this ADR.
