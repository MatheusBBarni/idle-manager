# ADR-003: Astro `site/` on project GitHub Pages with locale prefixes

## Status

Accepted

## Date

2026-08-30

## Context

The PRD needs a public player page that is not the Electron renderer. The repo has no website seam (`src/main|preload|renderer|shared` only, no `.github/`). ADR-001 already preferred GitHub Pages + Astro. The user locked the canonical URL as the project Pages site and PT/EN as `/en/` and `/pt/` prefixes.

Putting the landing in `src/renderer` would mix chrome with a public document and violate `AGENTS.md` (no game/docs in the chrome renderer; site is not a game view, but it still must not ride the Electron session).

## Decision Drivers

- Canonical URL `https://matheusbarni.github.io/idle-manager/` (TechSpec Q, A)
- Locale prefixes `/en/` and `/pt/` (TechSpec Q, A)
- Astro official Pages deploy: `site` + `base: /idle-manager`, `withastro/action` ([docs](https://docs.astro.build/en/guides/deploy/github/))
- Keep root `pnpm test` as `src/shared/**/*.test.ts` (`vitest.config.ts`, `AGENTS.md`)
- Do not load games, iframes, or WebContentsView on the site

## Decision

Add a **new** Astro static app at `site/` in this repository.

- `site` config: `https://matheusbarni.github.io`, `base: '/idle-manager'`.
- Locales: `en`, `pt`; `prefixDefaultLocale: true`. Routes: `/idle-manager/en/`, `/idle-manager/pt/`. `/idle-manager/` redirects to `/idle-manager/en/`.
- Output: static/prerendered only. No Astro SSR adapter.
- Deploy: GitHub Actions (`withastro/action` + `actions/deploy-pages`) from this repo. Pages source = GitHub Actions.
- The Electron app does not import `site/`. Root `pnpm test` / `pnpm verify:isolation` stay unchanged. Site tests run with `pnpm --dir site test`.
- No HeroUI/React requirement on the site. Language switch is `<a>` between locale prefixes.
- Download probe is specified in ADR-004.

## Alternatives Considered

### Build-time Download only (`WINDOWS_DOWNLOAD_URL`)

- **Benefits:** Matches original G-03 withhold; no `api.github.com` from the browser.
- **Costs/risks:** Rebuild to enable Download.
- **Why not selected:** User chose runtime Releases API and approach A.

### Plain HTML in `docs/`

- **Benefits:** No Astro dependency.
- **Costs/risks:** Manual `base` and i18n; weaker fit to official Pages+Astro path.
- **Why not selected:** User chose Astro `site/`.

### User-site or custom domain

- **Benefits:** Unprefixed URL.
- **Costs/risks:** Extra repo or DNS.
- **Why not selected:** User chose project Pages URL.

## Consequences

### Positive

- Documented Pages + i18n path.
- Site isolated from Electron partitions.
- Shareable PT and EN URLs.

### Negative and trade-offs

- Prefixed URL (`/idle-manager/`).
- New toolchain (`site/` + Actions) beside Electron.
- Default locale is English at `/`; PT is `/pt/`.

### Risks and mitigations

- Broken assets if `base` omitted — Astro `base` + tests for prefixed hrefs.
- Root test/typecheck polluted — do not add `site/` to root Vitest include.

## Reversibility

High. Delete `site/` and the Pages workflow; unpublish Pages. Locale URLs would 404.
